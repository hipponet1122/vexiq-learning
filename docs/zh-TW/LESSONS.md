# 技能教學怎麼寫、怎麼審

29 個技能的教學放在 `web/lessons-a.js`（A、B 類）、`web/lessons-b.js`（C、D 類）、`web/lessons-c.js`（E、F 類），流程引擎是 `web/learn.js`。流程是 **先猜猜看 → 看懂它 → 試試看 → 小檢查 → 動手做**，然後才是練習題。

## 一課的結構
```js
W.B3 = {
  min: 10,                                   // 預估分鐘（5～15）
  guess: { q, opts, a, why },                // 選填：先猜（a 是正確選項的索引）
  cards: [{ t, b, tip?, warn?, svg? }],      // 3～4 張「看懂它」卡片；b 是可信任的 HTML
  lab: { type, ask, ... } | [ ... ],         // 互動小工具，見下表
  check: [ Q(題目, 選項, 答案索引, 解釋, 積木?) ×3 ],   // 小檢查：3 題答對 2 題就過
  doit: { t, why?, steps, note, links },     // 動手做，以及要寫進工程筆記的內容
  extra: '<p>…</p>',                         // 選填：進階補充（中高熟練度才展開）
};
```

## 互動小工具（`lab.type`）
| 類型 | 孩子做什麼 | 主要欄位 |
|---|---|---|
| `calc` | 拉滑桿／選單，即時看結果 | `params`、`outs`（函式）、選填 `viz`（回傳 SVG 文字） |
| `walk` | 自己排前進／轉彎，看機器人走的路線 | `start`、`rep`、`noRep` |
| `trace` | 一步一步執行，看變數怎麼變 | `code`（程式行）、`steps`（`line`、`vars`、`note`） |
| `match` | 連連看：名詞配說明 | `pairs` |
| `order` | 照正確順序點步驟 | `steps` |

## 寫作規則
- 台灣用語的正體中文，白話、適合國小高年級；一張卡只講一件事，先舉生活例子再講規則。
- 題目需要的數字都寫在題目裡，不依賴特定零件規格；數字是假設的，標籤要寫「示意」。
- 積木文字沿用站內寫法，例如 `驅動 [向前] 為 (200) [毫米]`。一般句子不要用積木字眼（設定、重複、等待、將…）開頭又含括號，英文擷取工具會當成程式碼略過。
- SVG 文字或需要拼接的字串，每一段中文要獨立成字串，才翻得到。
- 事實要有來源（官方手冊或 VEX 知識庫）；當季規則要跟 `web/content.js` 的 `SEASON` 一致。
- 改完文字後：`node tools/i18n_extract.js` → 用 `python3 tools/i18n_todo.py <區域>` 列出未翻的句子、補進 `i18n/en/<區域>.tsv` → `python3 tools/i18n_build.py` → `node tests/run.js`。

## 進度怎麼存
`state.lrn[技能id] = { s, d, c, w }`：走到第幾步（1～5）、通過日期、小檢查最佳答對數、累計答錯數。刻意很小（伺服器限制每位學員進度 100 KB）。
